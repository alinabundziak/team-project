## Запуск проєкту

### Необхідні інструменти
- Node.js 24 LTS
- npm
- Git
- VS Code

### Встановлення

1. Клонувати репозиторій.
2. Відкрити папку проєкту у VS Code.
3. Встановити залежності:

```powershell
npm install
```

4. Запустити сервер:

```powershell
npm run dev
```

5. Перевірити адреси:
- http://localhost:3000/health
- http://localhost:3000/children

### Структура модулів

Кожен модуль знаходиться у `src/modules/`.

- `*.routes.js` — маршрути API
- `*.controller.js` — обробка запитів і відповідей
- `*.service.js` — бізнес-логіка

### Правила роботи

- Не працювати безпосередньо в `main`.
- Для кожної задачі створювати окрему гілку.
- Після завершення створювати Pull Request.
- Готовий код перевіряє QA.
- Тестові дані у `children.service.js` тимчасові.
- База даних буде підключена після погодження її структури.
