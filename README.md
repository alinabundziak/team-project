## 2. Завдання проєкту

**Мета:** розробити Backend-систему для управління дітьми, батьками, групами, персоналом, кімнатами, заняттями, розкладом та оплатами приватного дитячого садка.

**Особлива умова:** не використовувати SQL-транзакції; забезпечувати необхідні перевірки й обробку помилок на рівні програмного коду.

## 3. Запуск проєкту

### Необхідні інструменти

- Node.js 24 LTS
- Express.js
- PostgreSQL + Prisma (інтеграція в процесі)
- Git / GitHub
- Postman

### Встановлення

1. Клонувати репозиторій.
2. Відкрити папку проєкту у VS Code.
3. Встановити залежності:

`npm install`

4. Запустити сервер:

`npm run dev`

5. Перевірити адреси:

- http://localhost:3000/health
- http://localhost:3000/children

## 4. Структура проєкту

- `src/app.js` — налаштування Express та підключення маршрутів.
- `src/server.js` — запуск сервера.
- `src/modules/` — модулі системи.
- `*.routes.js` — маршрути API.
- `*.controller.js` — обробка запитів і відповідей.
- `*.service.js` — бізнес-логіка.
- `prisma/schema.prisma` — схема бази даних.
- `tests/test-cases.md` — документація ручного QA-тестування.

## 5. Правила роботи з GitHub

1. Не працювати безпосередньо в `main`.
2. Для кожної задачі створювати окрему гілку.
3. Після завершення задачі виконувати commit і push.
4. Створювати Pull Request у `main`.
5. Код перевіряє інший Dev, функціональність тестує QA.
6. Merge виконується після погодження з Team Lead.
7. Не завантажувати `.env`, паролі та токени.

Перевірено:
- `GET /health`
- `GET /children`
- структуру відповіді `/children`
- повторні запити
- обробку невідомого маршруту
- валідність Prisma-схеми

Автоматизовані тести наразі не налаштовані.
